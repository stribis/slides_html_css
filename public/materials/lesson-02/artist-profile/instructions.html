Artist Profile Workshop

Style the Nova Vale artist profile. For the first 20 minutes, do not edit the HTML. The goal is to practice selector choice, cascade control, and modern units.

Required steps

  1. Add a modern reset with box-sizing: border-box.
  2. Set readable base typography, page color, and background color.
  3. Use clamp() for the main heading size.
  4. Use min-height: 100svh or 100dvh on the hero section.
  5. Style the navigation with class selectors.
  6. Use an attribute selector for external links.
  7. Use :focus-visible for keyboard focus.
  8. Use :has(img) to style an image-based card.
  9. Create a clear card style for releases and shows.
  10. Write down one cascade conflict and explain the fix.

Stretch goals

  • Add cascade layers for reset, base, components, and utilities.
  • Use :where() for low-specificity base link styles.
  • Make the layout responsive with flexible widths and spacing.
