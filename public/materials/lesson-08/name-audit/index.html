Name Audit Lab

Audit links, buttons, images, and form controls. The page looks usable, but several controls have weak or missing accessible names.

Student Tasks

  • Rewrite vague link text so each link makes sense out of context.
  • Give icon-only buttons useful accessible names.
  • Decide whether each image is informative or decorative.
  • Connect every input to a real label.
