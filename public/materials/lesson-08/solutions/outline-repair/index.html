Outline Repair Solution

This solution keeps the original visual layout but repairs landmarks, navigation, heading order, and focus visibility.

What Changed

  • Added a skip link and a real <main> target.
  • Replaced generic layout containers with <header>, <nav>, <section>, and <footer>.
  • Used one page-level <h1>, then logical <h2> and <h3> headings.
  • Removed the bad focus suppression by relying on the shared visible focus styles.
