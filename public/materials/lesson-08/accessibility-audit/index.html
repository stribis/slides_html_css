Hint Sheet

  1. Add a skip link and semantic landmarks inside the sample page.
  2. Repair heading order. The sample jumps from h2 to h4.
  3. Replace vague link text such as "Click here" and repeated "Choose".
  4. The hero image needs an alt decision: meaningful alt text or empty decorative alt.
  5. The fake button is focusable but does not activate like a button.
  6. Visible focus is suppressed in the sample CSS.
  7. Inputs need connected labels, autocomplete values, and clearer error text.
  8. The pale navigation links and color-only featured plan need stronger signals.
  9. The spinning badge needs a reduced-motion override.
  10. Test the sample at 200% zoom and a narrow viewport.
