Framework Showdown

Build the same event interface twice, then compare the markup, customization workflow, accessibility work, and final result.

View reference Bootstrap starter Tailwind starter

Required interface

  • Page header with title and short introduction
  • Three event cards with images and clear actions
  • Email registration form with a visible label
  • Useful narrow-screen layout

Required states

  • Visible keyboard focus
  • Hover state that is not the only cue
  • Readable contrast
  • One intentionally disabled action

Decision note

Write five lines explaining why you chose the framework, what it made easier, what felt awkward, and one risk you would watch in production.
