Lesson 12 workshop

Build a Small Style System

The starter works, but its Sass architecture is intentionally dated. Improve the source without changing the semantic HTML.

Setup

  1. Open this folder in a terminal.
  2. Run npm install.
  3. Run npm run sass:watch.
  4. Open the component page with a local server.

Tasks

  1. Create a settings/_index.scss entry point that forwards tokens and configuration.
  2. Create a tools/_index.scss entry point that forwards mixins and functions.
  3. Replace every Sass @import with namespaced @use.
  4. Expose surface, text, and accent values as CSS custom properties so the dark section can override them at runtime.
  5. Use a Sass map and @each to generate success, warning, and danger status modifiers.
  6. Add a reusable focus-ring mixin and apply it with :focus-visible.
  7. Inspect css/styles.css. Remove any source abstraction that creates unnecessary output.

Definition of done

The output has no Sass deprecation warnings, all controls have visible keyboard focus, theme values can change without recompiling, and the generated CSS remains easy to trace back to its source.
