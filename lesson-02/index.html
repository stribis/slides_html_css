Modern Selectors

:is() Groups Alternatives

:is(header, main, footer) a {
  color: #1f7a68;
}
header a main a footer a

Use :is() to avoid repeating the same selector ending.

Modern Selectors

:where() Keeps Specificity Low

:where(article, aside, nav) a {
  text-underline-offset: 0.2em;
}
matches links adds 0 specificity easy to override

Great for base styles because later component styles can still win easily.

Modern Selectors

:has() Selects by Relationship

.card:has(img) {
  border-color: #1f7a68;
}
card with img text-only card card with img

:has() lets a parent react to its children.

Cascade Layers Organize Priority

utilities components base reset

Layers let you say which groups of CSS should win before selector specificity is compared inside the same layer.

Why Use Layers?

reset

Normalize browser defaults without fighting component styles later.

base

Set typography, links, body color, and shared document behavior.

components

Style reusable patterns like cards, buttons, nav, and forms.

utilities

Small override classes that intentionally win.

Layer Example

@layer reset, base, components, utilities;

@layer base {
  a { color: #1f7a68; }
}

@layer components {
  .button { color: white; background: #151923; }
}

@layer utilities {
  .text-green { color: #1f7a68; }
}

A simple selector in a later layer can beat a more complex selector in an earlier layer.

Units Are Design Decisions

pxPrecise borders, shadows, tiny details.
remTypography and spacing that respect root size.
%Relative to available parent size.
vw / vhRelative to viewport width or height.
svh / lvh / dvhSmall, large, and dynamic viewport height for mobile browser chrome.
vi / vbViewport units that follow writing mode: inline and block.
cqw / cqhContainer-query units for component-aware sizing.
clamp()Fluid values with sensible minimums and maximums.

Viewport Units in Practice

100vh

Classic full viewport height, but can feel jumpy on mobile.

100svh

Small viewport height. Safer when browser controls are visible.

100dvh

Dynamic viewport height. Updates as browser controls expand or collapse.
