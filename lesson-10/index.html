Why Animate?

FeedbackA button responds after interaction.
OrientationA menu reveals where it came from.
ContinuityA state change feels connected instead of abrupt.
CharacterA brand or scene can feel alive.

Animation should explain, guide, or support mood. It should not fight the task.

CSS vs. JavaScript Animation

QuestionCSS is good when...JS is better when...
What triggers it?A class, state, pseudo-class, or media query.Complex user input or data changes drive it.
How complex?Few properties, predictable timing, repeatable sequence.Physics, scrubbing, timelines, interruption, or choreography.
Who owns state?The browser state is enough.App state decides what should happen next.
How interactive?Hover, focus, checked, open, loading, looping decoration.Drag, gestures, games, live charts, scroll-linked logic.

Pros of CSS Animation

declarative

Describe the motion in CSS near the visual design.

state-friendly

Works well with hover, focus, checked, open, and class changes.

reusable

Keyframes and transitions can become part of a design system.

performant

When using the right properties, browsers can optimize heavily.

Cons of CSS Animation

limited logic

CSS does not know your application rules.

hard interruption

Complex pause, reverse, scrub, or physics behavior gets awkward.

support details

Some modern motion features need fallbacks or testing.

overuse

Too much motion makes interfaces feel slow, noisy, or inaccessible.

When Animation Is Too Much

It delays the taskUsers wait for decoration before doing the next thing. It repeats foreverConstant motion steals attention from content. It surprises usersLarge movement appears without user action or context. It ignores preferencesNo reduced-motion fallback. It hides stateUsers cannot tell what changed after the animation ends.

Performance: Animate the Right Properties

Usually saferUse carefullyAvoid for frequent motion
transformfilterwidth, height
opacitybox-shadowtop, left
background-colormargin, padding

Layout-heavy properties can force the browser to recalculate and repaint more than necessary.

Reduced Motion Is Required Practice

@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms;
    animation-iteration-count: 1;
    scroll-behavior: auto;
  }
}

Better: replace large motion with opacity, color, or an immediate state change.

Transforms Change the Painted Result

.card.featured {
  transform: translateY(-0.35rem) rotate(-1deg);
  transform-origin: center;
}

Transforms do not move neighboring elements in layout. They change how the element is painted.

Transform Functions

Atranslate()
Bscale()
Crotate()
Dskew()

Use transforms for visual emphasis, not for document structure.

Transform Order Matters

Move, then rotate

transform:
  translateX(80px)
  rotate(20deg);

Rotate, then move

transform:
  rotate(20deg)
  translateX(80px);

Transform functions are applied in order, which changes the final result.

transform-origin

.door {
  transform-origin: left center;
  transform: rotateY(18deg);
}
center left edge bottom right

The origin is the hinge point for rotation and scaling.

Individual Transform Properties

.badge {
  translate: 0 -0.25rem;
  rotate: -3deg;
  scale: 1.05;
}

Modern CSS also supports individual translate, rotate, and scale properties.

Transform Side Effects

Stacking contextA transformed element can create a new layering context. Hit areaThe visible element may no longer match where you expected it in the layout. TextRotated or scaled text can become harder to read. CompositingTransforms are often efficient, but too many moving layers still cost memory.

Transitions Animate a State Change

.button {
  background: #efc84a;
  transform: translateY(0);
  transition:
    background-color 180ms ease,
    transform 180ms ease;
}

.button:hover {
  background: #e86f51;
  transform: translateY(-4px);
}

A transition needs a before state, an after state, and time between them.

Transition Longhand

transition-propertyWhich property should animate? transition-durationHow long should it take? transition-timing-functionHow should speed change over time? transition-delayShould it wait before starting? transition-behaviorCan discrete properties transition in supporting browsers?

Use Specific Properties

Too Broad

transition: all 300ms ease;

Unexpected properties may animate later.

Better

transition:
  color 180ms ease,
  transform 180ms ease;

Only the intended properties animate.

Timing Functions

FunctionFeelCommon use
linearConstant speed.Clocks, loaders, mechanical movement.
easeDefault browser easing.General UI if you do not choose another.
ease-outStarts fast, settles gently.Elements entering or responding.
ease-inStarts slowly, exits faster.Elements leaving.
cubic-bezier()Custom curve.Brand-specific motion feel.
steps()Jumps in fixed intervals.Clocks, sprite-like states, counters.

State Triggers for Transitions

:hoverPointer is over the element. :focus-visibleKeyboard-visible focus state. :checkedCheckbox or radio selection state. [open]<details> or <dialog> state. :popover-openPopover is visible.

Multiple Transitions

.card {
  transition:
    transform 180ms ease-out,
    box-shadow 180ms ease-out,
    background-color 300ms linear;
}

.card:hover,
.card:focus-within {
  transform: translateY(-6px);
  box-shadow: 12px 12px 0 rgb(21 25 35 / 0.18);
}

Modern Discrete Transitions

.menu {
  display: none;
  opacity: 0;
  transition:
    opacity 180ms ease,
    display 180ms allow-discrete;
}

.menu[open] {
  display: block;
  opacity: 1;
}

Discrete transitions are newer. Use them as enhancement, not the only way content appears.

Keyframes Animate a Sequence

@keyframes pulse {
  0%,
  100% {
    scale: 1;
  }

  50% {
    scale: 1.08;
  }
}

Use keyframes when two states are not enough.

Applying an Animation

.badge {
  animation-name: pulse;
  animation-duration: 1.6s;
  animation-timing-function: ease-in-out;
  animation-iteration-count: infinite;
}

Animation Properties

PropertyQuestionExample
animation-nameWhich keyframes?pulse
animation-durationHow long?800ms
animation-timing-functionWhat speed curve?ease-in-out
animation-delayWait first?200ms
animation-iteration-countHow many loops?infinite
animation-directionAlternate direction?alternate
animation-fill-modeKeep before/after styles?both
animation-play-statePause or run?paused

The Animation Shorthand

.loader {
  animation: spin 1s linear infinite;
}

.toast {
  animation: slide-in 260ms ease-out both;
}

Shorthand is compact, but students should know the longhand parts first.

Percentages Create Stages

@keyframes float-card {
  0% { translate: 0 0; }
  35% { translate: 0 -0.8rem; }
  70% { translate: 0 0.2rem; }
  100% { translate: 0 0; }
}

Use stages when motion needs a path, bounce, pause, or change of emphasis.

steps() Creates Jumps

.second-hand {
  animation: tick 60s steps(60, end) infinite;
}

@keyframes tick {
  to {
    rotate: 360deg;
  }
}

This is perfect for clock hands that move once per second.

Pause on Interaction

.scene:hover .cloud,
.scene:focus-within .cloud {
  animation-play-state: paused;
}

Useful for inspecting motion, respecting attention, and debugging animated scenes.

Multiple Animations

.ship {
  animation:
    sail 12s linear infinite,
    bob 1.8s ease-in-out infinite alternate;
}

Multiple animations can layer movement, but keep names and timing readable.
