Warm-up

What does a browser actually understand?

HTML CSS JavaScript

The browser turns text files into a page by building structure, applying style, and running behavior.

Three Languages, Three Jobs

Language Question it answers Example job
HTML What is this? A heading, paragraph, link, image, form field.
CSS How should it look? Layout, color, typography, spacing, motion.
JavaScript What should happen? Validation, state changes, menus, data updates.

Mental Model

Markup Is Not Programming

Markup language

Describes content and relationships so humans, browsers, search engines, and assistive tools can understand the document.

<nav> <article> <button>

Programming language

Makes decisions, stores state, reacts to input, and changes what happens next.

if (...) { ... }

Static Websites Are Still Real Websites

They can be fast, secure, and accessible.

They do not need a database for every use case.

They can still include forms, media, and JavaScript.

The usual entry file is still index.html.

URLs

Why Is It Called index.html?

https://example.com/ loads https://example.com/index.html

Web servers commonly look for an index file when a folder is requested.

Syntax

An HTML Element

<h1>My Website</h1>
opening tag content closing tag

Most elements have a start tag, content, and an end tag. Some elements, like <img>, do not wrap text content.

Attributes Add Information

<img
  src="https://placecats.com/200/200"
  alt="Placeholder cat image"
  width="180"
  height="180"
/>

Attributes can identify, configure, describe, or connect an element to another resource.

Structure

Nesting Creates Meaning

<section aria-labelledby="about-title">
  <header>
    <h2 id="about-title">About Me</h2>
    <p>Designer, developer, and student.</p>
  </header>
</section>

Parent, child, and sibling relationships become the document tree.

The Browser Builds a Tree

html head body header main footer h1 section p

Boilerplate

A Modern Starting Point

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My Basic Website</title>
  </head>
  <body>
    <h1>My Basic Website</h1>
  </body>
</html>

What Each Part Does

<!doctype html>

Use the current HTML parser mode.

lang="en"

Tell tools and assistive technology the page language.

charset="UTF-8"

Support modern text characters reliably.

viewport

Make the layout match device width on mobile.

Semantic HTML

Use the Element That Means the Thing

<header> <nav> <main> <section> <article> <aside> <figure> <footer>

Semantics improve accessibility, maintainability, search, and team communication.

Tag Lab

Pick the Strongest Element

Site navigation

<nav>, not just <div>

Independent blog post

<article>, not only <section>

Image plus caption

<figure> and <figcaption>

Clickable action

<button>, not a fake link

Ask students to defend the choices aloud. The point is not memorizing every element, but noticing intent.

Void Elements Do Not Wrap Content

Broken

<img src="https://placecats.com/320/200">
  Cat Profile
</img>

Better

<figure>
  <img src="https://placecats.com/320/200" alt="Cat resting on a sofa" />
  <figcaption>Cat Profile</figcaption>
</figure>
