Typography Is Interface Design

Property What it controls Example
font-familyTypeface and fallback stack.font-family: Inter, Arial, sans-serif;
font-sizeText size and hierarchy.font-size: 1.125rem;
font-weightLight, regular, bold, or variable weight.font-weight: 750;
font-styleNormal or italic style.font-style: italic;
line-heightVertical rhythm between lines.line-height: 1.55;
letter-spacingSpace between characters.letter-spacing: 0.08em;
text-transformVisual casing without changing the HTML text.text-transform: uppercase;
text-alignInline text alignment.text-align: center;
max-widthReadable line length, often called measure.max-width: 65ch;

CSS Variables Store Design Decisions

:root {
  --font-body: Inter, Arial, sans-serif;
  --font-display: "Fraunces", Georgia, serif;
  --step-0: 1rem;
  --step-1: 1.25rem;
  --measure: 65ch;
}

body {
  font-family: var(--font-body);
}

h1 {
  font-family: var(--font-display);
  font-size: var(--step-1);
  max-width: var(--measure);
}

Variables keep repeated choices consistent and make experiments faster.

Type Scale: Small System, Big Difference

:root {
  --step-0: 1rem;
  --step-1: 1.25rem;
  --step-2: 1.563rem;
  --step-3: 1.953rem;
}

h1 { font-size: var(--step-3); }
h2 { font-size: var(--step-2); }

A scale keeps headings related instead of randomly sized.

Fluid Type With clamp()

h1 {
  font-size: clamp(2.5rem, 8vw, 7rem);
  line-height: 0.95;
}
Small viewport 2.5rem min
Growing viewport 8vw preferred
Large viewport 7rem max

clamp(min, preferred, max) lets type grow with the viewport, then stop before it becomes awkward.

Self-Hosted Fonts Use @font-face

@font-face {
  font-family: "Studio Grotesk";
  src: url("fonts/studio-grotesk.woff2") format("woff2");
  font-weight: 400 900;
  font-display: swap;
}

Online vs. Self-Hosted Fonts

ChoiceProsCons
Online serviceEasy setup, many families, CDN deliveryThird-party dependency, privacy/legal questions, less control
Self-hostedMore control, fewer third-party requests, predictable deploymentMore setup, licensing responsibility, file optimization is on you
