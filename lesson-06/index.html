Format Decision Rules

Photo?

Try AVIF/WebP, fall back to JPEG when needed.

Logo or icon?

Use SVG when it is simple vector artwork.

Transparency?

Use PNG, WebP, AVIF, or SVG depending on content.

Animation?

Prefer video for real motion; GIF is usually heavy.

srcset Handles Resolution Choice

<img
  src="https://placecats.com/800/500"
  srcset="https://placecats.com/400/250 400w,
          https://placecats.com/800/500 800w,
          https://placecats.com/1400/875 1400w"
  sizes="(max-width: 700px) 90vw, 45vw"
  alt="Relaxed cat on a sofa"
/>

Use this when the same image should load at different file sizes.

<picture> Handles Source Choice

<picture>
  <source media="(max-width: 600px)" srcset="https://placecats.com/500/700" />
  <source srcset="https://placecats.com/1200/600" />
  <img src="https://placecats.com/800/500" alt="Cat sitting by a window" />
</picture>

Use this for art direction, different crops, or format fallbacks.

CSS Background Fallbacks

.hero {
  background-color: #151923;
  background-image:
    linear-gradient(rgb(0 0 0 / .35), rgb(0 0 0 / .35)),
    image-set(
      url("cat.avif") type("image/avif"),
      url("cat.webp") type("image/webp"),
      url("cat.jpg") type("image/jpeg")
    );
  background-size: cover;
}

Always include a background color. Use gradients for overlays and fallbacks.

SVG Needs More Than One Slide

vector

Scales cleanly at every size.

currentColor

Icons can inherit text color from CSS.

viewBox

Defines the internal coordinate system.

accessibility

Decorative icons use aria-hidden; meaningful graphics need names.

Inline SVG Icon Pattern

<button class="icon-button" aria-label="Download press kit">
  <svg aria-hidden="true" viewBox="0 0 24 24" width="24" height="24">
    <path d="M12 3v12m0 0 4-4m-4 4-4-4M5 21h14" />
  </svg>
</button>

The button has the accessible name. The decorative SVG is hidden.
