Normal Flow Is Already a Layout System

Block

Starts on a new line and fills available width.

Inline

Flows with text and ignores width and height.

Inline-block

Flows inline but accepts box dimensions.

Historical Context

Where Float Fits Today

Float is not your modern layout tool.

Use it mainly to understand older websites and text wrapping around images. Use Flexbox for one-axis layout and let the later Grid lesson handle two-axis page systems.

What Flexbox Is Good At

navigation

Logo on one side, links on the other, consistent gaps.

toolbars

Buttons aligned on one row with one item pushed away.

cards

Equal-height card footers and flexible card content.

media objects

Image plus text, avatar plus message, icon plus label.

Flexbox Starts on the Parent

Logo Projects About Contact 
.nav {
  display: flex;
}

Only the direct children become flex items.

Parent vs. Children

Flex container

The parent with display: flex. It controls direction, alignment, wrapping, and gaps.

Flex items

The direct children. They can grow, shrink, set a basis, change order, or align themselves.

Why it matters

gap belongs to the container. It avoids fragile margin rules on individual children.

align-content Needs Wrapped Lines

Common beginner trap:

align-content does nothing on a single flex line. It distributes multiple lines inside extra cross-axis space.

flex-basis Sets the Starting Size

.card {
  flex-basis: 18rem;
}

The basis is the size Flexbox starts from before growing or shrinking happens.

flex-grow Shares Extra Space

grow: 1 grow: 2 grow: 1 
.main { flex-grow: 2; }
.side { flex-grow: 1; }

flex-shrink Decides Who Compresses

Default:

Flex items have flex-shrink: 1, so they are allowed to become smaller than their starting size when space is tight.

.logo {
  flex-shrink: 0;
}

The flex Shorthand

ShorthandMeansUse case
flex: 1Grow and share the rowEqual columns or equal card widths
flex: 0 0 18remDo not grow, do not shrink, start at 18remFixed sidebar or fixed card basis
flex: 1 1 16remGrow, shrink, start at 16remResponsive wrapping cards

order Changes Visual Order

Use carefully.

order changes visual order, but not the source order or the default reading order. Do not use it to fix bad HTML structure.

Pattern: Equal Card Actions

.card {
  display: flex;
  flex-direction: column;
}

.card .button {
  margin-top: auto;
}

This keeps buttons aligned even when card text lengths differ.

What About Grid?

Keep the distinction simple for now.

Flexbox is strongest for one axis: rows or columns. Grid is strongest for two axes: rows and columns together. Grid gets its own future lesson, so today we only need the distinction.
