Box Model Vocabulary

content

The actual text, image, video, or child elements.

padding

Space inside the box, between content and border.

border

The line around padding and content.

margin

Space outside the border, between this box and other boxes.

content-box Adds Padding and Border

CSS

.box {
  width: 300px;
  padding: 20px;
  border: 4px solid;
  box-sizing: content-box;
}

Rendered width

300 + 20 + 20 + 4 + 4 = 348px

border-box Includes Padding and Border

CSS

.box {
  width: 300px;
  padding: 20px;
  border: 4px solid;
  box-sizing: border-box;
}

Rendered width

300px total

The content area becomes smaller so the whole box stays predictable.

Use This Reset

*,
*::before,
*::after {
  box-sizing: border-box;
}

This makes component widths behave the way most people expect.

Positioning

Positioning Changes the Coordinate System

normal flow offset box viewport

Before using top, right, bottom, or left, ask: relative to what?

Position Values

ValueRelative toUse case
staticNormal flowDefault document layout.
relativeItselfNudge an element or create a positioning context.
absoluteNearest positioned ancestorBadges, overlays, tooltips.
fixedViewportPersistent controls or banners.
stickyScroll containerHeadings or nav that stick while scrolling.

position: static

Default

The element stays in normal flow.

Offsets ignored

top, right, bottom, and left do not move static elements.

position: relative

original space remains moved visually 
.moved {
  position: relative;
  top: 24px;
  left: 48px;
}

The element moves visually, but its original space is still reserved.

position: absolute

positioned parent absolute child 
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 1rem;
  right: 1rem;
}

The Containing Block Rule

Absolute positioning searches upward.

An absolute element positions itself against the nearest ancestor that is not position: static. If none exists, it uses the initial containing block.

Offsets and inset

top: 1remPlace the top edge 1rem from the containing block's top edge right: 1remPlace the right edge 1rem from the containing block's right edge inset: 0Set top, right, bottom, and left to 0 inset-block: 1remSet logical block-start and block-end offsets inset-inline: auto 0Use logical inline offsets for writing-mode-aware layouts

position: fixed

fixed

Fixed elements stay attached to the viewport while the document scrolls behind them.

Useful for persistent controls, but easy to overuse on small screens.

position: sticky

sticky heading 
.section-title {
  position: sticky;
  top: 0;
}

Sticky starts in normal flow, then sticks after crossing the offset.

Layering Uses z-index

z-index: 1 z-index: 2 z-index: 3

z-index works on positioned elements and inside stacking contexts.

Stacking Contexts Are Mini Universes

A high z-index is not always enough.

If an element is inside a lower stacking context, it cannot escape above a sibling stacking context just by using a giant number.
